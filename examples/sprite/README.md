# Audio Sprite Visual

## Description

This example visualizes how audio sprites work and demonstrates how they can be used within @nkzw/audio. Click on a sprite on the waveform to play it back and watch the progress (multiple clicks will overlap sounds).

- Audio sprite support with single audio file.
- Displays playback progress of sprites in real-time.
- Allows playback of multiple sprites on top of each other.
- Full-screen and responsive for desktop/mobile.

## Run locally

Run `vp run dev` from the repository root and open this example from the examples index.
