# Live Streaming Audio

## Description

This example displays how to use @nkzw/audio to stream live audio, such as in this simple radio app.

- Controls: start, stop.
- Allows switching between multiple live streams.
- Full-screen and responsive for desktop/mobile.

## Run locally

Run `vp run dev` from the repository root and open this example from the examples index.
